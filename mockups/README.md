# Especificación y documentación de mockups — ZoFranca CR

Este documento presenta los lineamientos visuales, las especificaciones, los prompts utilizados y las evidencias de los cinco mockups principales de **ZoFranca CR**.

Los diseños fueron generados con Google Stitch y sirvieron como referencia para desarrollar la aplicación funcional con HTML, CSS y JavaScript.

## Proyecto de Google Stitch

[Ver proyecto ZoFranca CR en Google Stitch](https://stitch.withgoogle.com/projects/15403820050885334695)

## 1. Sistema de diseño

### Paleta de colores

| Uso | Color | Código |
|---|---|---|
| Primario | Azul institucional | `#1e3a8a` |
| Secundario | Azul cian | `#0284c7` |
| Éxito | Verde esmeralda | `#10b981` |
| Advertencia | Ámbar | `#f59e0b` |
| Error o alerta | Rojo coral | `#ef4444` |
| Fondo | Gris claro | `#f8fafc` |
| Superficie | Blanco | `#ffffff` |
| Texto principal | Azul grisáceo oscuro | `#0f172a` |
| Texto secundario | Gris | `#64748b` |

### Tipografía

La interfaz utiliza una tipografía sans-serif moderna, preferiblemente **Inter**, con una jerarquía clara para títulos, subtítulos, indicadores, formularios y tablas.

### Componentes principales

- Barra lateral de navegación.
- Barra superior con buscador y controles de usuario.
- Tarjetas blancas con bordes y sombras sutiles.
- Formularios con etiquetas visibles.
- Tablas y paneles de indicadores.
- Etiquetas de estado con colores accesibles.
- Botones primarios y secundarios.
- Indicadores de evaluación mediante IA.
- Alertas de cumplimiento.
- Diseño adaptable y consistente.

### Estados visuales

| Estado | Color |
|---|---|
| Aprobada / En regla | Verde |
| Recomendada | Azul |
| Pendiente / En revisión | Ámbar |
| Rechazada / Incumplimiento | Rojo |
| Información neutral | Gris o azul claro |

## 2. Solicitud de instalación

Esta pantalla permite registrar una nueva solicitud de ingreso a una zona franca y consultar las solicitudes existentes.

### Elementos principales

- Nombre de la empresa.
- Cédula jurídica.
- Zona franca.
- Sector económico.
- Inversión proyectada.
- Empleos proyectados.
- Nombre y correo del contacto.
- Referencia documental.
- Botón para enviar la solicitud.
- Tabla de solicitudes registradas.
- Filtros por estado, sector y texto.
- Puntaje o clasificación de IA.
- Enlace para consultar el detalle.

### Prompt utilizado en Google Stitch

```text
Design a modern and clean web application screen for “ZoFranca CR - Solicitud de Instalación”. Use a professional Costa Rican institutional style with a navy blue sidebar, white cards and a light gray background. Include a form titled “Nueva Solicitud” with fields for company name, legal identification, free zone, economic sector, projected investment, projected jobs, contact name, contact email and document reference. Beside the form, include a table titled “Solicitudes Registradas” with status badges, AI score and actions. Use Inter typography and accessible colors.
